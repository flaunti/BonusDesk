# История изменений

## 2.2.0

- автоматическая смена календарной недели заменена ручным созданием отчётных периодов;
- добавлен выбор произвольных дат нового периода с проверкой пересечений;
- добавлены массовые действия «Засчитать все», «Вернуть на проверку все» и «Удалить все»;
- массовое одобрение оставляет проблемные отчёты на проверке;
- установщик получил фирменное оформление BonusDesk;
- кнопка выбора каталога установки открывает современный системный проводник;
- в приложении и документации добавлена информация об авторе Edward Saint;
- версия приложения обновлена до 2.2.0.

## 2.1.0

- добавлен раздел «Быстрый список» для готовых выплат без проверки отчётов;
- поддержан формат `Имя | Static ID | должность | сумма`;
- добавлены сверка итоговой суммы, объединение повторных Static ID и контроль нераспознанных строк;
- отдельный комментарий экспорта быстрого списка — `Премия GOV` по умолчанию;
- добавлена проверка обновлений через GitHub Releases;
- добавлены публичная Windows-сборка, portable-архив и установщик через GitHub Actions;
- добавлены Windows-метаданные версии приложения.

## 2.0.0

- приложение переименовано в BonusDesk и отделено от конкретной организации;
- полностью переработан интерфейс и создан новый логотип;
- доказательства отображаются отдельными кликабельными ссылками;
- добавлена поддержка нескольких ссылок и поиск их повторного использования;
- экспорт всегда начинается с `staticId;amount;comment`.
