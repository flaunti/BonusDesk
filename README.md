# BonusDesk 2.1.0

BonusDesk — настольное приложение для проверки отчётов и формирования премий. Работает на одном компьютере, хранит историю по неделям и не требует отдельного сайта.

## Возможности

- импорт структурированного отчёта из буфера обмена;
- ручное добавление и исправление отчётов;
- автоматическое сопоставление работ по названиям и алиасам;
- кликабельные ссылки на доказательства, включая несколько ссылок на одну работу;
- изменение принятого количества и цены прямо при проверке;
- поиск повторно использованных доказательств и повторных отчётов;
- суммирование всех одобренных отчётов по Static ID;
- недельный лимит выплаты — 150 000 по умолчанию;
- экспорт TXT с обязательным заголовком `staticId;amount;comment`;
- быстрый импорт готовых списков выплат без проверки отчётов;
- сверка указанной итоговой суммы, объединение повторяющихся Static ID и поиск нераспознанных строк;
- архив недель и автоматические резервные копии базы;
- автоматическая проверка новых версий через GitHub Releases.

## Быстрый список выплат

Открой раздел **«Быстрый список»** и вставь строки в формате:

```text
Alex Example | 100001 | 15 | 100.000$
Maria Example | 100002 | 14 | 100.000$

Итоговая сумма: 200.000$
```

BonusDesk извлечёт Static ID и суммы, проверит общий итог и подготовит:

```text
staticId;amount;comment
100001;100000;Премия GOV
100002;100000;Премия GOV
```

Служебные строки без суммы не попадают в экспорт. Для быстрого списка лимит премии не применяется.

## Запуск из исходников

Требуется Python 3.11 или новее.

```text
pip install -r requirements.txt
python main.py
```

В Windows можно запустить `run_windows.bat`: он создаст виртуальное окружение и установит зависимости.

Для обычного пользователя предназначен `BonusDesk-Setup-x64.exe` на странице [Releases](https://github.com/flaunti/BonusDesk/releases). Установщик не требует заранее установленного Python.

## Сборка Windows-приложения

Запусти `build_windows.bat`. Готовое приложение появится здесь:

```text
dist\BonusDesk\BonusDesk.exe
```

Для переноса на другой компьютер скопируй всю папку `BonusDesk` из каталога `dist`.

`build_installer.bat` дополнительно создаёт установщик через Inno Setup 6.

## Формат экспорта

```text
staticId;amount;comment
100001;150000;Премия
100002;122000;Премия
```

Лимит и текст комментария меняются в настройках приложения.

## Обновления

Проект: [github.com/flaunti/BonusDesk](https://github.com/flaunti/BonusDesk)

BonusDesk проверяет последний опубликованный GitHub Release не чаще одного раза в день. Автоматическую проверку можно отключить в настройках. При отсутствии интернета все остальные функции продолжают работать.

Публикация тега вида `v2.1.0` автоматически собирает Windows-версию и прикрепляет архив к GitHub Release.
